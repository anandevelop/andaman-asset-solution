# SEO Analytics — คำสั่งสำหรับ Claude Code

คู่กับ `docs/SEO_ANALYTICS_PLAN.md` (เอกสารออกแบบ) และ mockup
`Claude outputs/seo-analytics-mockup.html` — ไฟล์นี้คือ **วิธีสั่งลงมือ**

## วิธีใช้

คำสั่งอยู่ใน `.claude/commands/seo-phase-*.md` เปิด Claude Code ใน VS Code แล้วพิมพ์:

```
/seo-phase-0
```

ต่อท้ายด้วยข้อความอะไรก็ได้เพื่อเพิ่มข้อจำกัดเฉพาะครั้ง เช่น

```
/seo-phase-1 ทำแค่ rule engine + test ก่อน ยังไม่ทำ UI
/seo-phase-4 ยังไม่มี credential ทำเฉพาะส่วนที่ test ด้วย fixture ได้
/seo-phase-6 ยังไม่มีเฟส 4 ออกรายงานจากข้อมูลเฟส 1–3 ไปก่อน
```

แต่ละคำสั่งเช็คเองว่าเฟสที่ต้องมาก่อนเสร็จหรือยัง และหยุดถ้ายัง

---

## ทั้งหมด 7 คำสั่ง

| คำสั่ง | ทำอะไร | ประเมิน | ต้องมีก่อน | ใช้ Google |
|---|---|---|---|---|
| `/seo-phase-0` | แก้ robots.txt ของ staging + env ใหม่ใน `lib/env.ts` | 0.5 วัน | — | ไม่ |
| `/seo-phase-1` | On-Page Audit: 15 กฎ, คะแนน, ประวัติ, ยกเว้นกฎ, CSV | ~5 วัน | 0 | ไม่ |
| `/seo-phase-2` | Core Web Vitals + TTFB | ~2 วัน | 1 | ไม่ |
| `/seo-phase-3` | เรียลไทม์ + **เก็บ landing/referrer ให้เฟส 6** | ~2 วัน | — | ไม่ |
| `/seo-phase-4` | Search Console / URL Inspection → tab คำค้นเดิม | ~5 วัน | 1 | **ต้อง** |
| `/seo-phase-5` | Indexation funnel + bot log | ~3 วัน | 2, 4 | ใช้ผลเฟส 4 |
| `/seo-phase-6` | รายงาน + อีเมล + แจ้งเตือน | ~4 วัน | 3 | ไม่บังคับ |

**ลำดับที่แนะนำตอนนี้** (ยังไม่ได้ย้ายไปโดเมนจริง จึงยังไม่มี credential):
`0 → 1 → 3 → 2 → 6` ระหว่างรอโดเมนจริง แล้วค่อย `4 → 5` หลังเปิดโดเมนและตั้ง Google เสร็จ

เฟส 3 ขึ้นมาก่อนเฟส 2 ในลำดับนี้ เพราะเฟส 3 เริ่มเก็บ landing/referrer ของ lead ซึ่ง
**ย้อนหลังไม่ได้** — ยิ่งขึ้น production เร็ว รายงานเฟส 6 ยิ่งมีข้อมูลให้ใช้

## กติกาที่ใช้กับทุกเฟส

- **หนึ่งเฟส หนึ่ง branch หนึ่ง PR** เช่น `seo/phase-1` — อย่าให้เฟสเหลื่อมกัน
- `npm run verify` คือประตู อย่ารายงานว่าเสร็จถ้ายังไม่ผ่าน (ตาม `AGENTS.md`)
- คำสั่งเฟส 1 แบ่งเป็น 3 ขั้นและ **หยุดให้รีวิวทุกขั้น** — อย่าสั่งให้ข้าม
- ถ้า Claude เจอปัญหานอกเฟส ให้ **รายงานอย่างเดียว ห้ามแก้** — ทุกคำสั่งเขียนกำกับไว้แล้ว
- มี migration ทุกเฟสยกเว้นเฟส 0 — อ่าน migration ที่สร้างก่อน merge ทุกครั้ง
- **ห้ามวาง private key ลงในแชตกับ Claude** หรือไฟล์ใดที่ commit — ใส่ใน `.env` บน server เอง
