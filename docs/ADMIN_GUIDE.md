# คู่มือผู้ดูแลเว็บไซต์

สำหรับทีมงานที่ดูแลเนื้อหาเว็บไซต์ Andaman Asset Solution
ไม่ต้องมีความรู้ด้านโปรแกรมมิ่ง

---

## เข้าสู่ระบบ

เปิด **https://andamanassetsolution.com/th/login** แล้วกรอกอีเมลกับรหัสผ่านที่ได้รับ

หลังเข้าระบบครั้งแรก แนะนำให้เปลี่ยนรหัสผ่านทันที โดยคลิกชื่อตัวเองที่มุมล่างซ้าย

> **ลืมรหัสผ่าน** ระบบยังไม่มีปุ่ม "ลืมรหัสผ่าน" ให้แจ้งผู้ดูแลสูงสุด
> เพื่อตั้งรหัสใหม่ให้ที่หน้า ผู้ใช้งาน
>
> **กรอกรหัสผิดหลายครั้ง** หากกรอกผิดเกิน 10 ครั้งภายใน 15 นาที
> ระบบจะล็อกชั่วคราว รอ 15 นาทีแล้วลองใหม่

## หลักการสำคัญ: ฉบับร่าง กับ เผยแพร่

ทุกอย่างในระบบมีสวิตช์ **"เผยแพร่"**

- **ไม่ติ๊ก** = ฉบับร่าง เห็นได้เฉพาะในระบบหลังบ้าน คนทั่วไปมองไม่เห็น
- **ติ๊ก** = ขึ้นเว็บไซต์จริง

**แนะนำให้ทำงานแบบนี้เสมอ** สร้างเป็นฉบับร่างก่อน → กรอกให้ครบ → ตรวจทาน → ค่อยติ๊กเผยแพร่

ทุกอย่างที่บันทึกจะขึ้นเว็บภายในไม่กี่วินาที ไม่ต้องรอ ไม่ต้องแจ้งใคร

## เพิ่มโครงการใหม่

**โครงการ → เพิ่มโครงการ**

### ข้อมูลที่ต้องเตรียมก่อน

- ชื่อโครงการ ทั้งไทยและอังกฤษ
- ที่ตั้ง เช่น "พาซัก 8 เชิงทะเล ภูเก็ต"
- รูปหลัก 1 รูป และรูปแกลเลอรีอีก 3–6 รูป
- ราคาเริ่มต้น จำนวนยูนิต พื้นที่โครงการ
- โบรชัวร์ PDF (ถ้ามี)

### กรอกทีละส่วน

**1. ชื่อและ URL**

ชื่อโครงการกรอกทั้งสองภาษา ส่วน **URL slug** คือชื่อที่จะปรากฏในลิงก์
ใช้ตัวพิมพ์เล็ก ตัวเลข และขีดกลางเท่านั้น

> ตัวอย่าง กรอก `trinity-village` จะได้ลิงก์
> `andamanassetsolution.com/th/projects/trinity-village`

⚠️ **หลังเผยแพร่แล้วอย่าเปลี่ยน slug** เพราะลิงก์เดิมที่เคยส่งให้ลูกค้า
หรือที่ Google เก็บไว้จะใช้ไม่ได้ทันที

**2. ข้อความโปรยและรายละเอียด**

ข้อความโปรยคือประโยคสั้นใต้ชื่อโครงการ ส่วนรายละเอียดคือเนื้อหาเต็ม

กรอกทั้งสองภาษา หากกรอกภาษาเดียว ระบบจะแสดงภาษาที่มีให้ผู้เข้าชมทุกคน
ซึ่งดีกว่าปล่อยว่าง แต่ไม่ดีเท่ากรอกครบ

**3. ข้อมูลจำเพาะ**

จำนวนยูนิต พื้นที่ (ตร.ม.) ราคาเริ่มต้น (บาท)

ช่อง **สิ่งอำนวยความสะดวก** พิมพ์บรรทัดละหนึ่งรายการ โดยใช้คำเหล่านี้
เพื่อให้มีไอคอนแสดง — `clubhouse` `fitness` `security` `pool` `garden` `concierge`

**4. รูปภาพ**

ลากไฟล์มาวาง หรือคลิกเลือกไฟล์

- **รูปหลัก** ใช้เป็นภาพใหญ่ด้านบนสุดของหน้าโครงการ และใช้เป็นภาพหน้าแรกด้วย
- **แกลเลอรี** ใส่ได้หลายรูป **ลำดับสำคัญ** — รูปแรกจะแสดงในส่วนภาพรวม
  จัดลำดับได้โดยลากที่จุดจับมุมขวาบน หรือกดปุ่มลูกศร
- รองรับ JPEG, PNG, WebP, AVIF ไม่เกิน 15MB ต่อรูป
- **โบรชัวร์** รับเฉพาะ PDF ไม่เกิน 30MB จะขึ้นเป็นปุ่มดาวน์โหลดในหน้าโครงการ

> รูปควรกว้างอย่างน้อย 1600px และย่อขนาดไฟล์ก่อนอัปโหลด
> รูปจากกล้องมักใหญ่เกินจำเป็นและทำให้เว็บโหลดช้า

**5. SEO**

Meta title และ meta description คือข้อความที่ปรากฏในผลการค้นหา Google

เว้นว่างได้ ระบบจะใช้ชื่อโครงการและข้อความโปรยแทน แต่ถ้าเขียนเองจะควบคุมได้ดีกว่า
ความยาวที่เหมาะสมคือ title ไม่เกิน 60 ตัวอักษร description ไม่เกิน 155 ตัวอักษร

**6. เผยแพร่**

ติ๊ก "เผยแพร่บนเว็บไซต์" แล้วกดบันทึก

**ลำดับการแสดง** ตัวเลขน้อยขึ้นก่อน ถ้าอยากให้โครงการไหนอยู่บนสุดของหน้าแรก ให้ใส่ `0`

## อัปเดตความคืบหน้าการก่อสร้าง

**โครงการ → เปิดโครงการ → แท็บ "ความคืบหน้าการก่อสร้าง"**

> เดิมเป็นเมนู "ความคืบหน้า" แยกในแถบซ้าย ตอนนี้อยู่ในหน้าโครงการนั้น ๆ
> ลิงก์เดิมที่บุ๊กมาร์กไว้ยังใช้ได้ ระบบจะพาไปที่ใหม่ให้เอง
> ถ้าอยากดูทุกโครงการเทียบกัน: **โครงการ → แท็บ "ความคืบหน้าประจำเดือน"**

ระบบเตรียมเดือนถัดไปให้อัตโนมัติ ไม่ต้องเลือกเอง

1. ใส่หัวข้อ เช่น "งานหลังคาเฟส A"
2. เขียนสรุปสั้น ๆ ว่าเดือนนี้ทำอะไรไปบ้าง
3. อัปโหลดรูปหน้างาน จัดลำดับตามต้องการ
4. ติ๊กเผยแพร่ แล้วบันทึก

> **ทำทุกเดือน แม้เดือนที่งานช้า** เว็บไซต์บอกผู้ซื้อว่าเราเผยแพร่ทุกเดือน
> เดือนที่หายไปทำให้ลูกค้าสงสัยมากกว่าเดือนที่แจ้งว่าล่าช้า

## เขียนข่าวหรือบทความ

**ข่าวสาร → เขียนบทความ**

### การจัดรูปแบบข้อความ

ช่องเนื้อหาใช้รูปแบบ **Markdown** ซึ่งเป็นวิธีจัดรูปแบบด้วยเครื่องหมายง่าย ๆ

| พิมพ์แบบนี้ | ได้ผลลัพธ์ |
|---|---|
| `## หัวข้อใหญ่` | หัวข้อขนาดใหญ่ |
| `### หัวข้อรอง` | หัวข้อขนาดรอง |
| `**ข้อความ**` | **ตัวหนา** |
| `*ข้อความ*` | *ตัวเอียง* |
| `- รายการ` | รายการแบบจุด |
| `1. รายการ` | รายการแบบตัวเลข |
| `> ข้อความ` | ข้อความยกมา |
| `[ข้อความ](https://ลิงก์)` | ลิงก์ |

เว้นบรรทัดว่างหนึ่งบรรทัดระหว่างย่อหน้า

### หมวดหมู่และแท็ก

**หมวดหมู่** จะกลายเป็นปุ่มกรองในหน้ารวมบทความ ควรใช้ชื่อเดิมซ้ำ
ช่องกรอกจะขึ้นรายการที่เคยใช้ให้เลือก

**แท็ก** คั่นด้วยเครื่องหมายจุลภาค เช่น `ownership, legal, foreign buyers`

### ตั้งเวลาเผยแพร่ล่วงหน้า

ติ๊กเผยแพร่ แล้วใส่**วันที่ในอนาคต** บทความจะยังไม่ขึ้นเว็บจนกว่าจะถึงเวลานั้น

ในหน้ารายการจะเห็นป้าย "ตั้งเวลาไว้" สีส้ม

ถ้าเว้นวันที่ว่าง ระบบจะเผยแพร่ทันที

## สร้างกิจกรรม

**กิจกรรม → เพิ่มกิจกรรม** (ต้องมีสิทธิ์ผู้ดูแลระบบขึ้นไป)

1. ชื่อกิจกรรมทั้งสองภาษา และ URL slug
2. **วันและเวลาเริ่ม** — เวลาที่กรอกคือเวลาไทย ไม่ต้องแปลง
3. **เวลาสิ้นสุด** ไม่บังคับ แต่ถ้าไม่ใส่ ระบบจะถือว่ากิจกรรมจบทันทีที่เริ่ม
   และหน้าเว็บจะย้ายไปหมวด "กิจกรรมที่ผ่านมา" ทันที
4. **จำนวนที่นั่ง** นับรวมผู้ติดตามของแต่ละคน เช่น คนหนึ่งลงทะเบียนมา 4 คน
   จะนับเป็น 4 ที่นั่ง เว้นว่างหากไม่จำกัด
5. ติ๊กเผยแพร่ แล้วบันทึก

### ดูรายชื่อผู้ลงทะเบียน

เปิดกิจกรรมนั้นขึ้นมา รายชื่อจะอยู่ด้านบนสุด พร้อมเบอร์โทรและอีเมลที่กดโทร/ส่งได้เลย

เปลี่ยนสถานะได้จากช่องด้านขวา — รอยืนยัน / ยืนยันแล้ว / ยกเลิก / มาร่วมงาน / ไม่มาตามนัด

> **ที่นั่งเต็ม** เมื่อจองครบ ระบบจะปิดรับอัตโนมัติและแสดงข้อความให้ผู้เข้าชม
> หากยกเลิกรายการใด ที่นั่งจะคืนกลับเข้าระบบทันที
>
> **ลดจำนวนที่นั่งไม่ได้ถ้ามีคนจองเกิน** ระบบจะเตือน ให้ยกเลิกรายการจองก่อน

## จัดการรายชื่อผู้สนใจ

**รายชื่อผู้สนใจ**

ทุกครั้งที่มีคนกรอกฟอร์มบนเว็บ รายการจะเข้ามาที่นี่ และแจ้งเตือนเข้า LINE ทีมขายทันที

### เปลี่ยนสถานะ

คลิกที่ช่องสถานะแล้วเลือก ระบบบันทึกให้ทันทีโดยไม่ต้องกดบันทึก

**ใหม่ → ติดต่อแล้ว → ผ่านการคัดกรอง → นัดชมโครงการแล้ว → อยู่ระหว่างเจรจา → ปิดการขาย / ไม่สำเร็จ**

การเปลี่ยนสถานะให้ตรงความจริงสำคัญ เพราะกราฟอัตราปิดการขายในหน้าภาพรวมคำนวณจากตรงนี้

### ส่งออกเป็นไฟล์ Excel

กดปุ่ม **ส่งออก CSV** มุมขวาบน (ต้องมีสิทธิ์ผู้ดูแลระบบ)

- ไฟล์ที่ได้จะตรงกับตัวกรองที่เลือกอยู่ ถ้ากรองเฉพาะ "ใหม่" ไฟล์จะมีเฉพาะรายการใหม่
- กด "ช่วงวันที่" เพื่อเลือกช่วงเวลา เช่น รายงานประจำเดือน
- เปิดด้วย Excel หรือ Google Sheets ได้ทันที ภาษาไทยไม่เพี้ยน

> ⚠️ ไฟล์นี้มีชื่อ เบอร์โทร และอีเมลของลูกค้า ถือเป็นข้อมูลส่วนบุคคลตาม PDPA
> เก็บในที่ปลอดภัย ไม่ส่งต่อโดยไม่จำเป็น และลบเมื่อใช้เสร็จ

## เสียงจากลูกค้า และ คำถามที่พบบ่อย

**เสียงจากลูกค้า** — ข้อความชื่นชมจากเจ้าของบ้าน

- **ผูกกับโครงการได้** ข้อความที่ผูกไว้จะแสดงเป็นลำดับแรกในหน้าโครงการนั้น
  ซึ่งน่าเชื่อถือกว่าข้อความทั่วไปมาก
- ช่องคะแนนดาวเว้นว่างได้ ข้อความที่ดีไม่จำเป็นต้องมีดาว
- ⚠️ ต้องได้รับอนุญาตจากเจ้าของข้อความก่อนเผยแพร่เสมอ

**คำถามที่พบบ่อย** — คำตอบที่แสดงในหน้าแรกและหน้าโครงการ

ช่อง **หมวดหมู่** สำคัญ เฉพาะสี่หมวดนี้เท่านั้นที่จะไปแสดงในหน้าโครงการด้วย

`ownership` (การถือครอง) · `payment` (การชำระเงิน) · `construction` (งานก่อสร้าง) · `aftercare` (หลังส่งมอบ)

หมวดอื่นจะแสดงเฉพาะหน้าแรก

ช่องคำตอบใช้ Markdown เหมือนบทความ

## ดูรายงาน

**งานวันนี้** (หน้าแรกหลังเข้าระบบ) ตอบว่า *วันนี้ต้องทำอะไร* อย่างเดียว

- **การ์ดสี่ใบด้านบน** ทั้งใบเป็นลิงก์ กดแล้วไปที่หน้าซึ่งทำงานนั้นได้เลย
  (ลีดที่ยังไม่มีคนรับ / เกินเวลาตอบกลับ / นัดชมวันนี้ / รอตรวจก่อนเผยแพร่)
- **สรุปเดือนนี้** ลีดใหม่ · นัดชมโครงการ · ปิดการขาย

**รายงานและสถิติ** (เมนู "การตลาด") คือที่เดียวของกราฟทั้งหมด

- เลือกช่วงเวลาและกดส่งออก CSV ได้ที่มุมขวาบน (ย้ายมาจากหน้าภาพรวม)
- **แท็บทราฟฟิก** ยอดเข้าชม สถานะการเชื่อม GA4 / Meta Pixel / Search Console
  และอัตราการยินยอมคุกกี้
- **แท็บเนื้อหา** บทความที่คนอ่านมากที่สุด ยอดลงทะเบียนกิจกรรม และ
  **ตารางอัตราปิดการขาย** ซึ่งคิดจากรายที่ **ติดตามแล้วจริง** เท่านั้น
  ไม่นับรายใหม่ที่ยังไม่ได้โทร เพื่อไม่ให้สัปดาห์ที่มีคนสนใจเยอะดูเหมือนผลงานแย่ลง
- **แท็บลีด** กราฟผู้สนใจรายเดือน (ย้อนหลัง 12 เดือน — แท่งสีน้ำเงินคือจำนวนที่
  เข้ามา สีทองคือที่ปิดการขายได้) ช่องทางที่ลีดมาจาก และไปป์ไลน์งานขาย

## แก้ข้อมูลติดต่อ

**หน้าเว็บไซต์ → แท็บ "ติดต่อเรา"** (ต้องมีสิทธิ์ผู้ดูแลระบบขึ้นไปจึงจะบันทึกได้)

> เดิมอยู่ใน "ตั้งค่า" ตอนนี้อยู่รวมกับหน้าอื่น ๆ ของเว็บไซต์
> **ที่อยู่และเวลาทำการ** เลือกภาษาจากแถบ TH / EN / ZH / RU ด้านบน
> แล้วกรอกทีละภาษา เหมือนหน้าอื่นที่มีหลายภาษา — บันทึกภาษาหนึ่ง
> ไม่กระทบอีกสามภาษา

แก้เบอร์โทร อีเมล ที่อยู่ เวลาทำการ LINE OA และลิงก์โซเชียลได้เอง
มีผลกับทั้งเว็บทันทีหลังบันทึก

- ช่องที่ยังไม่เคยแก้จะขึ้นว่า "ค่าเริ่มต้น" และแสดงค่าปัจจุบันเป็นตัวอย่างจาง ๆ
- **ล้างช่องให้ว่างแล้วบันทึก = กลับไปใช้ค่าเริ่มต้น**
- ช่อง "เบอร์โทร (สำหรับลิงก์ tel:)" ต้องใส่รหัสประเทศ เช่น `+66 76 123 456`
  ส่วน "เบอร์โทรที่แสดงบนเว็บ" คือรูปแบบที่คนอ่าน เช่น `076-123-456`

**Analytics & SEO** — ตัวเชื่อมต่อ (GA4 / Meta Pixel) อยู่ที่ **ตั้งค่า → การเชื่อมต่อภายนอก**
ส่วนค่า SEO ของทั้งเว็บ (ชื่อหน้าเริ่มต้น รูปแชร์ รหัสยืนยัน Search Console)
ย้ายไปที่ **SEO → แท็บ "ค่าเริ่มต้นทั้งเว็บ"**

- **Meta Pixel ID** — รหัส Pixel จาก Facebook Events Manager (ตัวเลขล้วน
  เช่น `1234567890123456`) ใส่แค่ตัวเลข ไม่ต้องคัดลอกโค้ดสคริปต์ทั้งชุดมาวาง
  ใส่แล้วเว็บจะเริ่มส่งข้อมูล PageView และการกรอกฟอร์มไปที่ Pixel นี้ทันที
- **รหัสยืนยัน Google Search Console** — ตอนยืนยันเว็บไซต์ใน Search Console
  ให้เลือกวิธี "HTML tag" ระบบจะให้แท็กมาแบบ
  `<meta name="google-site-verification" content="xxxxxxxx" />` — คัดลอกมาแค่
  ค่าในเครื่องหมายคำพูดหลัง `content=` (ส่วน `xxxxxxxx`) มาวางในช่องนี้
  ไม่ต้องใส่ทั้งแท็ก

> ข้อความแบรนด์ ชื่อบริษัท และหน้านโยบายความเป็นส่วนตัว แก้ที่นี่ไม่ได้
> ต้องให้นักพัฒนาแก้ ซึ่งตั้งใจให้เป็นแบบนี้เพื่อให้มีการตรวจทานก่อนขึ้นจริง

## เพิ่มผู้ใช้งาน

**ผู้ใช้งาน** (เฉพาะผู้ดูแลสูงสุด)

กรอกชื่อ อีเมล เลือกสิทธิ์ และตั้งรหัสผ่านอย่างน้อย 12 ตัวอักษร

> ให้สิทธิ์ต่ำที่สุดที่ทำงานได้ คนเขียนเนื้อหาใช้ "ผู้แก้ไขเนื้อหา" ก็เพียงพอ
>
> **ควรมีผู้ดูแลสูงสุดอย่างน้อยสองคน** ระบบไม่ยอมให้ลบคนสุดท้ายออก
> ถ้ามีคนเดียวแล้วลืมรหัส ต้องให้นักพัฒนาเข้าไปแก้ที่เซิร์ฟเวอร์

**พนักงานลาออก** ให้ปิดสวิตช์ "เปิดใช้งานบัญชีนี้" แทนการลบ
เขาจะเข้าระบบไม่ได้ทันที แต่ประวัติการทำงานยังอยู่ครบ

## ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| แก้แล้วหน้าเว็บไม่เปลี่ยน | กด Ctrl+Shift+R (Mac: Cmd+Shift+R) เพื่อล้างแคชเบราว์เซอร์ ถ้ายังไม่หายให้ตรวจว่าติ๊ก "เผยแพร่" แล้วหรือยัง |
| อัปโหลดรูปไม่ได้ | ตรวจนามสกุลไฟล์ (JPEG/PNG/WebP/AVIF) และขนาดไม่เกิน 15MB ถ้าขึ้นว่า "ยังไม่ได้ตั้งค่าที่เก็บรูปภาพ" ให้แจ้งนักพัฒนา |
| รูปขึ้นเป็นกรอบว่าง | URL รูปเสียหรือไฟล์ถูกลบไปแล้ว ลบออกแล้วอัปโหลดใหม่ |
| กดบันทึกแล้วขึ้นสีแดง | อ่านข้อความใต้ช่องที่เป็นสีแดง มักเป็น slug ซ้ำหรือกรอกข้อมูลไม่ครบ |
| เข้าระบบไม่ได้ | รอ 15 นาทีถ้าเพิ่งกรอกผิดหลายครั้ง แล้วลองใหม่ ถ้ายังไม่ได้ให้แจ้งผู้ดูแลสูงสุด |
| ไม่ได้รับแจ้งเตือน LINE | แจ้งนักพัฒนา อาจเป็นเรื่องการตั้งค่าฝั่งเซิร์ฟเวอร์ |
| หน้าเว็บขึ้นข้อความสีเหลืองว่าเชื่อมต่อฐานข้อมูลไม่ได้ | แจ้งนักพัฒนาทันที ระบบยังแสดงหน้าเว็บได้แต่ข้อมูลจะว่าง |

## สรุปสิ่งที่ควรจำ

1. **สร้างเป็นฉบับร่างก่อนเสมอ** ตรวจให้ครบแล้วค่อยติ๊กเผยแพร่
2. **กรอกทั้งสองภาษา** ทุกครั้งที่ทำได้
3. **อย่าเปลี่ยน URL slug หลังเผยแพร่แล้ว**
4. **ย่อรูปก่อนอัปโหลด** เว็บที่โหลดเร็วขายได้ดีกว่า
5. **อัปเดตสถานะผู้สนใจให้ตรงความจริง** รายงานทั้งหมดคำนวณจากตรงนั้น
6. **ไฟล์ CSV คือข้อมูลส่วนบุคคล** ดูแลตามนั้น
